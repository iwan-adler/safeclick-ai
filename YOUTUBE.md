## Description

```
Is that message real, or a scam? SafeClick AI checks suspicious messages, screenshots and whole chats on your own device. It explains every warning sign word by word, and it never uploads anything.

▶ Try it: https://safeclick-ai-mu.vercel.app
💻 Code: https://github.com/iwan-adler/safeclick-ai

Built for Next Byte Hacks V5.

WHAT IT DOES
• Screenshot checking: text is read in the browser by self-hosted OCR, and the image never leaves your phone
• Every warning explained: tap a highlighted phrase to see why it is risky and what to do instead
• Conversation mode: catches the "friendly first, then a request for money" pattern behind romance and investment scams
• Made for India: UPI PIN and QR tricks, KYC/PAN/Aadhaar, "digital arrest", *401* call-forwarding codes, in English, Hinglish and Hindi
• Link X-ray: shows the real domain and catches look-alike letters (like a Cyrillic "о" posing as "o")
• Warn your family: a warning card in Hindi or English for WhatsApp
• Already paid? A step-by-step plan that puts India's 1930 cyber-fraud helpline first, plus a masked incident report
• Simple mode for elders: Hindi first, three big buttons, read-aloud, one-tap call to family, and it never says "safe"

MEASURED HONESTLY
On real SMS scams it had never seen, with an evaluation plan published before running it:
• 85% of new real-world scams flagged (the first version caught 14%)
• 0.3% false alarms on 2,393 genuine texts
• 85% on an independent set of Hindi/Hinglish messages
Full report, with confidence intervals and caveats: https://github.com/iwan-adler/safeclick-ai/blob/main/eval/RESULTS.md

PRIVATE BY DESIGN
No account, no server analysis, no analytics. Explainable rules plus a 56 KB machine-learning model run entirely in your browser. A Content-Security-Policy blocks the page from sending data anywhere else.

BUILT WITH
Next.js · React · TypeScript · Tailwind CSS · tesseract.js (WebAssembly) · PWA with Android share target · Playwright · Vitest · axe-core
260 unit tests and 42 browser tests run on desktop and mobile. Automated WCAG 2.1 AA audit: zero violations.
```
